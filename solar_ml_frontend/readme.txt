HOW TO RUN THIS REACT APP
=========================
1. Make sure Nodejs is installed
2. You can do that by following the steps here; choose your specific operating system: https://nodejs.org/en/download
3. Open this folder in Visual Studio Code
4. Open a terminal and type:

npm install  

5. Node Package Manager will install all the dependencies for this project

6. Once this is done, run:
 npm start 

to run the app
